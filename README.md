# dota2-regressor
Простой предсказатель победы в гре дота 2 на основе информации первых 10 минут матча

Первым делом приведем наши файлы к надлежащему виду и соберем все в одну таблицу. В качестве признаков были выбраны пики героев, статистика по золоту/опыту за 5/10/15 минуты матча, количество упавших с каждой стороны башен, а также кто сделал first blood.
